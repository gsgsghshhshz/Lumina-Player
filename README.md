# Lumina Player Pro 🎬

Professional Video Player with Persian subtitle support

## Features

### Video Playback
- ExoPlayer with hardware acceleration
- HDR10+ Support
- Auto Frame Rate
- Picture-in-Picture
- Speed control (0.25x to 2x)

### Gesture Controls (Like MX Player)
- Double tap left: Rewind 10s
- Double tap right: Forward 10s
- Double tap center: Play/Pause
- Drag left: Brightness
- Drag right: Volume
- Drag center: Seek

### Subtitle Customization
- Font size (12-48)
- Color (Gold, White, Yellow, Cyan)
- Outline width
- Shadow
- Background opacity
- Vertical position

### Professional Controls
- Screen lock
- Manual brightness
- Manual volume
- Playback speed
- Progress bar

## Tech Stack
- Kotlin
- Jetpack Compose
- Media3 ExoPlayer
- Material Design 3

## Installation
1. Download APK file
2. Enable Unknown Sources
3. Install APK
